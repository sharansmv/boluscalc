I want to create an Insulin Bolus Calculator web application on Replit. This application will help people with diabetes calculate their insulin doses based on various factors.

## Core Functionality
The app should calculate insulin doses based on:
- Current glucose level vs. target glucose level
- Carbohydrates, proteins, and fats to be consumed
- Insulin sensitivity factor
- Time-based insulin-to-carb ratios (different for each hour of the day)
- Active insulin on board (IOB)
- Selected insulin type with appropriate action profiles

The algorithm should implement these formulas:
- CU = Carbohydrates/[User's Carb Ratio] (not fixed at 10, but based on user settings)
- FPU = (Proteins * 4.0 + Fats * 9.0)/100
- CU_perc = CU/(CU + FPU)
- Correction = (glucose - target)/sensitivity
- Normal Bolus calculation based on CU_perc values
- Square Bolus calculation with appropriate timing
- Pre-meal timing recommendations based on selected insulin type

## Insulin Types Database
Implement a database of common rapid-acting insulin types with these properties:
- Onset time (how quickly it starts working)
- Peak time (when it works the hardest)
- Duration (how long it stays active)
- Recommended pre-meal timing (how long before eating to take it)

Include at least these common rapid-acting insulins:
- NovoRapid/NovoLog (insulin aspart)
- Humalog (insulin lispro)
- Apidra (insulin glulisine)
- Fiasp (faster-acting insulin aspart)
- Lyumjev (ultra rapid lispro)
